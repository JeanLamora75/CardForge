# Lexique joueur Skydeck

Amiral / Admiral : appellation du joueur. Lieutenant 11, Commandant 12, Amiral 13, Navire légendaire 14 : unités stratégiques. Corsaire libre / Free corsair : joker technique. Unité, faction, puissance, flotte active, renforts, réserves, rappel. Les termes traditionnels restent dans la documentation technique et les identifiants internes. Les captures ennemies sont définitives, distinctes des réserves. Les crédits Card Capture et les règles restent inchangés.
