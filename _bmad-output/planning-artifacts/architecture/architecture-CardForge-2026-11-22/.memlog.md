- constraint | CardForge vise Web responsive puis Android et iOS ; pas d'IDE installé ni de droits administrateur sur le poste Windows.
- constraint | Les règles originales ne doivent jamais être modifiées par l'habillage visuel ; Clear the Dungeon Classic 1.1.0 sans réserve facultative.
- decision AD-01 | React Web partagé et Capacitor pour Android/iOS ; empêche trois implémentations métier.

- decision AD-06 | Tests unitaires métier, intégration et parcours par plateforme ; empêche validation uniquement visuelle.
- decision AD-07 | Ressources graphiques et sonores embarquées, structurées par jeu ; empêche dépendance réseau à l'usage.
- decision AD-08 | PWA Web avec cache hors ligne + ressources embarquées Capacitor ; empêche panne offline après installation.
- decision AD-09 | Format/version de règles explicites, migrations transactionnelles ; empêche perte de progression et changement silencieux des règles.
- decision AD-10 | Service applicatif coordonnant moteur, état, sauvegarde et résultat ; empêche doublons et règles dans React.
- decision AD-11 | Validation, erreurs catégorisées et récupération non destructive ; empêche perte silencieuse.
- decision AD-12 | GitHub Actions pour Web puis builds Android/iOS sur runners adaptés ; empêche dépendance aux IDE locaux.

- assumption | Les versions installables Capacitor/CI et leurs contraintes actuelles ne sont pas vérifiées en ligne pour ce livrable.

- question | Les cas limites de Clear the Dungeon restent bloquants pour déclarer un moteur conforme.
